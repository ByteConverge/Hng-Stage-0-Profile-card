# HNG Stage 0 & 1 - Profile Card & Multi-Page Application

A responsive and accessible web application featuring a profile card, about page, and contact form with validation. Built with vanilla HTML, CSS, and JavaScript following modern web development practices.

## 🚀 Live Demo
https://profile-card-ebon-nu.vercel.app/

## 📁 Project Structure
Hng-Stage-0-Profile-card/
├── index.html # Profile Card (Stage 0)
├── about.html # About Me Page (Stage 1)
├── contact.html # Contact Us Page (Stage 1)
├── style.css # Complete styling (Responsive)
├── app.js # JavaScript functionality
├── me.jpg # Profile picture
└── README.md # Project documentation



## 🎯 Project Overview

### Stage 0: Profile Card
A responsive profile card component that displays:
- Personal information and bio
- Dynamic current time in milliseconds
- Social media links
- Hobbies and dislikes lists
- Accessible design with proper semantic HTML

### Stage 1: Multi-Page Extension
Extended the single card into a complete 3-page application:

**1. Profile Page (`index.html`)**
- Original profile card with enhanced navigation
- Real-time clock display
- Social links opening in new tabs

**2. About Me Page (`about.html`)**
- Personal reflections and journey
- Goals in the HNG program
- Areas of improvement
- Future notes and additional thoughts

**3. Contact Us Page (`contact.html`)**
- Fully validated contact form
- Real-time error messages
- Success confirmation
- Accessible form controls

## ✨ Features

### 🎨 Design & UX
- **Responsive Design**: Mobile-first approach with desktop optimization
- **Consistent Styling**: Uniform color scheme and visual hierarchy
- **Smooth Animations**: Hover effects and transitions
- **Glassmorphism Effects**: Modern translucent backgrounds with blur

### ♿ Accessibility
- **Semantic HTML**: Proper use of `<article>`, `<section>`, `<nav>`, etc.
- **ARIA Attributes**: Accessible form validation and navigation
- **Keyboard Navigation**: Full keyboard support
- **Screen Reader Friendly**: Proper labels and descriptions

### 📱 Responsive Navigation
- **Desktop**: Full-width fixed navbar with centered menu
- **Mobile**: Hamburger menu with animated transitions
- **Touch-Friendly**: Adequate touch targets for mobile devices

### 🔧 Technical Features
- **Form Validation**: Real-time client-side validation
- **Dynamic Content**: Live time updates every second
- **Cross-Browser Compatible**: Works on modern browsers
- **Performance Optimized**: Minimal and efficient code

## 🛠️ Technologies Used

- **HTML5**: Semantic markup and accessibility
- **CSS3**: Flexbox, Grid, animations, and responsive design
- **Vanilla JavaScript**: DOM manipulation and form validation
- **Git**: Version control and deployment
